# Counter-evidence

Counter-evidence may show:

- consent/permission/license;
- quote/news/education/satire context;
- platform record contradicting allegation;
- edited/corrected current snapshot;
- missing transaction intent;
- different target/author association.

It must use Evidence IDs and the same provenance/quality rules. Model disagreement is not
counter-evidence. Material unresolved counter-evidence forces `CONFLICTED`/manual.
