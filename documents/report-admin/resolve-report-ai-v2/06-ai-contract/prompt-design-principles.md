# Prompt Design Principles — Contract 2.0

1. System instructions contain authority, supplied rules, evidence semantics and schema.
2. Report/target/evidence are serialized untrusted data.
3. Model evaluates only Backend-supplied candidate Rule IDs.
4. Finding must cite Evidence IDs.
5. Reporter claim/count/prior AI output are not facts.
6. Missing/conflict triggers manual.
7. Explanation is rationale, not evidence.
8. No tools, web access or mutation capability in Sprint 1.
9. USER/CAFE_PAGE never reach provider.
10. Prompt/version/model identity is pinned and returned.

Prompt must prefer a correct abstention over a confident unsupported conclusion.
