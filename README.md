# cafe-story-platform
A multi-platform social media application for coffee lovers, supporting web and mobile experiences.

# To run java spring backend 
- first you have to clone project, and then
    git checkout develop
    To see backend

- then you have you config the .env which variable in application.properties. In this project we use subbase and postgres SQL

# To run the FE 
- npm i then

- npm run dev

# the rule of the branch on git

- if you want to do some feature. First 
    git checkout develop
    and then git pull to pull the new code

- then you create new branch 

    git checkout -b <branch name>

    the branch name which follows the rule

    for example: javaSpring/feature/<service name>

    for example in fe: nextJs/feature or Page or Screen (react natice)/<name of the context>
